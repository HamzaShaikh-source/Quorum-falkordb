## 1. REST & SSE API Outline

### 1.1 Authentication & Tenant Context
- Header: `Authorization: Bearer <token>`
- Token payload extracts `{ tenant_id: str, role: "agent" | "auditor" | "human", agent_id?: str }`.
- Gateway injects tenant into DB graph context `tenant_<id>:commons`.
- No request payload ever accepts `tenant_id` or `origin`.

### 1.2 Endpoints (Serving Person 3 & External Clients)

#### Graph & Node Inspection
- `GET /graph?as_of=<timestamp_ms>`
  - Returns nodes, edges, statuses, and blast depth info.
  - Passes through to `graph.queries.as_of(t)` or `graph.queries.graph_snapshot()`.
- `GET /node/{id}`
  - Returns node details, provenance chain, quote, source origin, status history.

#### Live Event Feed
- `GET /events`
  - Server-Sent Events (SSE) stream.
  - Event payload format: `event: <event_type>\ndata: {"type": ..., ...}\n\n`
  - Event types:
    - `node_added`: `{ id, label, status, text, key }`
    - `status_changed`: `{ id, status, depth, quarantine_root }`
    - `epoch_changed`: `{ epoch }`
    - `gate_blocked`: `{ action_id, reason, handoff_id }`
    - `action_executed`: `{ action_id, confirmed }`
    - `compensation_updated`: `{ compensation_id, target_action_id, status }`
    - `handoff_claimed`: `{ handoff_id, winner, losers: [] }`
    - `invariant_status`: `{ ok: bool, violations: [] }`

#### Scenario Driver (Demo / Presentation)
- `POST /scenario/{step}`
  - Steps: `inject_poison`, `run_agents`, `audit`, `supersede`, `restore`, `reset`
  - Triggers seeded scenario transitions for deterministic presentation.

#### Blast Radius
- `GET /blast/{id}/preview`
  - Dry-run query: returns affected facts, conclusions, actions without mutating state.
- `GET /blast/{id}/report`
  - Historical containment statistics (ms to containment, counts quarantined vs compensated).

#### Handoffs & Human Review Queue
- `GET /handoffs?status=...&kind=...`
  - Returns list of handoffs.
- `POST /handoffs/{id}/claim`
  - Agent token allowed for `kind=TASK` only.
  - Requires `role=human` or `role=auditor` for `REVIEW` / `ESCALATION`.
- `POST /handoffs/{id}/review`
  - Body: `{ resolution: "APPROVED" | "REJECTED", notes: str }`
  - Requires `role=human`. If `APPROVED` on a gate-blocked action, sets `gate=PASSED`.

#### Ledger & Procedures
- `GET /actions`
  - Returns staged, executed, blocked, and compensated actions.
- `GET /procedures`
  - Returns procedures with steps, uses, successes, failures, and Laplace-smoothed ranks.
- `GET /prompt-diff`
  - Before/after prompt context diff showing quarantined context removal.

#### Company Brain (Track 03)
- `POST /brain/ask`
  - Body: `{ question: str }`
  - Returns: `{ answer: str, citations: [{ source, title, url, version, quote }], owner_team: str, freshness: str }`
  - Refuses untraceable answers: `{ error: "no sourced answer found" }`.
- `GET /who-knows?topic=<topic>`
  - Returns leaderboard of Person nodes ranked by `AUTHORED|RESOLVED` evidence.

#### System, Observability & Benchmarks
- `GET /invariants`
  - Live invariant status (e.g. zero healthy nodes under quarantined parents).
- `GET /cypher-log`
  - Recent query log `{ name, cypher, ms, rows }` from Person 1's query library.
- `GET /bench/results`
  - Reads `bench/results.json` generated by `make proof`.
- `GET /tenants/denied-demo`
  - Demonstrates cross-tenant rejection live for judges.

## 2. State Machine Sketches

### 2.1 Action State Machine
```
              [stage_action]
                    |
          (Atomic Derivation Check)
                    |
           [Quorum Gate Evaluation]
          /                        \
    (gate=PASSED)             (gate=BLOCKED: Irreversible & uncorroborated)
        |                                   |
    status=HEALTHY                     status=HEALTHY
    executed=false                     executed=false
    gate=PASSED                        gate=BLOCKED
        |                                   |
  [execute_action]                     [Create REVIEW Handoff]
  (Atomic Execute Guard)                    |
  Bad=0?                               [Human Review: Approve]
   /        \                               |
 (No)       (Yes)                      gate=PASSED
  |           |
(Abort)   executed=true, confirmed=false
              |
          (Call Mock Helpdesk API)
          /        \
       (200 OK)    (Network Failure / Crash > 60s)
          |                 |
     confirmed=true   (In-flight Saga takes over)

[Any stage: On Quarantine Cascade]
  -> status=QUARANTINED
  -> If executed=true -> Enqueue Compensation
  -> If executed=false -> Action remains quarantined (will never execute)
```

### 2.2 Handoff State Machine
```
           [Created (TASK, REVIEW, ESCALATION)]
                          |
                   status=PENDING
                          |
              [POST /handoffs/{id}/claim]
         (Role Check: TASK=Agent/Human/Auditor,
          REVIEW/ESCALATION=Human/Auditor only)
         (Anchor Health Check: Anchor must be HEALTHY if kind=TASK)
                          |
                  status=IN_PROGRESS
                  claimed_by=agent/human_id
                  claimed_at=timestamp()
                  lease_until=now + 60000ms
                 /                          \
       (Lease expires / Worker crash)     (Complete)
               |                               |
       status=IN_PROGRESS (lease_until < now)  status=COMPLETED
               |                               |
       (New claimer claims it)            (If REVIEW on Gate:
               |                           set Action.gate='PASSED')
       status=IN_PROGRESS (new claimer)
```

### 2.3 Compensation State Machine (Outbox Saga Worker)
```
          [Action QUARANTINED & executed=true]
                          |
               (MERGE 'comp_' + action.id)
                          |
             status=PENDING_COMPENSATION
                          |
                  [Outbox Worker Poll]
                          |
                  status=DISPATCHING
                  lease_until=now + 30000ms
                          |
            (Call Mock Helpdesk /revert or /reverse)
            (Includes Action.idempotency_key)
           /                                 \
       (200 OK)                           (Error / Timeout)
          |                                       |
    status=COMPENSATED                    attempts++, backoff
                                                  |
                                            attempts >= MAX?
                                            /              \
                                          (No)             (Yes)
                                           |                 |
                                status=PENDING_COMPENSATION status=FAILED
                                                     + Create ESCALATION Handoff
```
